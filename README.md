# Data Structures & Algorithms

A personal repository for learning, practicing, and reviewing **Data Structures & Algorithms using TypeScript**.

The goal is to understand the underlying patterns and problem-solving techniques rather than simply memorizing solutions.

## Tech Stack

* TypeScript
* Node.js
* `tsx`
* Git & GitHub

## Approach

For each problem, I aim to:

1. Understand the problem
2. Develop a brute-force solution
3. Analyze time and space complexity
4. Identify a more efficient approach
5. Implement the solution
6. Test the solution
7. Review the pattern and key concepts

## Goal

Build strong problem-solving skills and develop a deeper understanding of common DSA patterns used in technical interviews and software development.
